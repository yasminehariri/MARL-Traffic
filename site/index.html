The problem

Sixteen junctions, sixteen minds

We simulate a city of 16 traffic lights on a 4×4 grid in SUMO, a standard traffic simulator. Each junction is controlled by its own AI agent, trained with reinforcement learning.

Every agent sees only its own junction: the queue on each of its four roads, which direction is currently green, and how long it has been green. From that, it chooses which direction to turn green next.

The question: do agents that can send messages to their neighbours control traffic better, and can they invent those messages themselves instead of using a format we designed?

Each dot is a junction with its own agent. The highlighted one sees the four queues feeding into it.

Robustness · sensor failure

When a junction goes blind

All four sensors at junction B1 break and read zero cars. Real signals handle this by falling back to a fixed timer for that junction. We tested both: leaving the AI running, and switching on the fallback.

E1 with junction B1 blind (left) against the same with the fixed-time fallback (right). The broken junction is marked in red in the viewer.

Priority · emergency vehicles

Clearing the way for an ambulance

A city controller is not only about average waiting time. In every test episode, 11 ambulances cross the city, one every 5 minutes, each passing at least 3 junctions. We ran every controller twice on exactly the same traffic and the same ambulances: once treating ambulances like any other car, and once with signal priority.

How priority works. When an ambulance is on the road leading into a junction, that light turns green for the ambulance's direction; if several are close, the nearest is served first. This is a simple rule added on top of each controller, not something the agents learned, and it never shortens the 3-second yellow or the 5-second minimum green.

What we measure. The ambulance's travel time, from when it was due to leave until it arrives (an ambulance still on the road when the hour ends counts with its time so far), and the delay of all the other vehicles, to see what priority costs everyone else.

Generalisation

Trained small, runs big

We trained E1 on a small 2×2 grid, then dropped it onto the 4×4 city with no retraining at all. It still beats the fixed-time controllers.

Honest test · attribution

Is it the messages?

E1 differs from B1 in two ways: it can talk to its neighbours, and it uses a different, much smaller network trained with an extra loss. To separate the two, we trained a control: E1's exact network and training, with every incoming message replaced by zeros, so it can never communicate.

Reliability

Trained three times, same result

We trained E1 and B1 three times each (seeds 0, 1, 2) to show the headline is not luck. E1 lands in the same place every time; B1 does not.
