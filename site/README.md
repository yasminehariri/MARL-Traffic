# Results website (`site/`)

This is a static website that presents the project's results. It has no build step and no server code. It is published on GitHub Pages by `.github/workflows/pages.yml` at https://yasminehariri.github.io/MARL-Traffic/. The full brief and roadmap are in the Word guide, "Website Roadmap and Developer Guide".

| Path | What it is | Who edits it |
|---|---|---|
| `data/*.json` | Every result number, generated by `scripts/export_site_data.py`. The format is in [`data/README.md`](data/README.md) | nobody (regenerate instead) |
| `js/data.js` | Loads the data and gives `loadData`, `pick`, `one`, `fmt`, `nameOf` | only if needed |
| `check.html` | Data check: compares the data with the final report. It must be all green before publishing | nobody |
| `index.html` and everything else | The website | the web developer |
| `../demo/` | The 3D replay viewer, embedded with an `<iframe>` (see [`../demo/README.md`](../demo/README.md)) | nobody |

## Run it locally

From the **repo root** (not from `site/`), so that `../demo/` works exactly as it does online:
```
python -m http.server 8000
```
Then open http://localhost:8000/site/ and http://localhost:8000/site/check.html.

## Rules

1. Load every number through `js/data.js`. Never type a result into the HTML.
2. Load every library from a file in the repo (`site/vendor/`), not a CDN, so the site also works offline at the defence.
3. Paths are relative (`js/data.js`, `../demo/index.html`), never starting with `/`. The site lives under `/MARL-Traffic/`.
4. Before every push, check that `check.html` is all green and `python tests/test_viewer.py` passes.
